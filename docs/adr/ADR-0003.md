# ADR-0003:数据镜像 secret 存储暂用 core config 表,生产前替换

- 状态:Accepted(用户于 2026-08-04 确认)
- 日期:2026-08-04
- 关联:PRD §20.5 / AGENTS §19.4(开放项"secret backend")

## 背景

数据镜像需要保存 SSH 私钥 / PAT。候选:core config 表(现状,明文)、
环境变量注入 + 配置只存引用、外部 secret 后端(vault 等)。

## 决策

本轮**保持 core config 表存储**,并满足:

- secret 永不进入 public 投影、日志、Git 仓库或客户端响应(AGENTS §13);
- 代码与文档明确标注"生产接入前必须替换为专用 secret 存储";
- 错误消息对 PAT 脱敏。

## 后果

- 单机部署当前可用;生产(尤其多实例/共享存储)前需按 ADR 更新替换,
  替换不影响 DataMirrorEngine 接口(仅 MirrorConfigStore 内部实现)。
