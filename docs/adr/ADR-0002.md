# ADR-0002:@atrium/* 版本策略采用统一版本

- 状态:Accepted(用户于 2026-08-04 确认)
- 日期:2026-08-04
- 关联:PRD §22 / AGENTS §21(开放项"包版本采用统一还是独立策略由 ADR 决定")

## 背景

Atrium 发布多个框架包与官方模块(contracts/core/ui/theme/server-host/web-host/
desktop-host/mcp-host/data-mirror/notes)。版本策略候选:统一版本(同步发版)
与每包独立版本(各自语义化发布)。

## 决策

采用**统一版本**:所有 `@atrium/*` 包使用同一版本号同步发布。

- 语义化版本(PRD §22 / AGENTS §21)仍然适用;
- AGENTS §21"各包可以独立发布"解释为**发布动作可分批发**,版本号保持统一;
- 应用锁定精确版本或受控范围,Atrium 发新版本不自动升级应用(PRD §22)。

## 后果

- 单个包的破坏性变更会提升整体主版本,发布节奏统一;
- 版本矩阵管理成本低;阶段 7/8 应用接入时按统一版本锁定。
