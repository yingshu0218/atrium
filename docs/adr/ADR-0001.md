# ADR-0001:数据镜像的 Git 执行采用系统 Git

- 状态:Accepted
- 日期:2026-08-04
- 关联:PRD §20 / AGENTS §19(开放项"Git 执行采用系统 Git 还是库实现")

## 背景

Data Mirror Engine 需要执行 clone/fetch/commit/push。选项:

1. 系统 `git` 子进程(spawn);
2. 纯 JS 实现(如 isomorphic-git,支持远程操作但认证生态较窄)。

## 决策

采用**系统 git 子进程**:

- 凭证经 `GIT_SSH_COMMAND`(SSH key 临时文件、权限 600)与 `GIT_ASKPASS`(PAT,
  经环境变量注入,不写入脚本文件)传递;
- 提交身份由服务端统一指定(`GIT_AUTHOR_*` / `GIT_COMMITTER_*`),不依赖全局配置;
- 单命令超时、输出脱敏(secret 替换为 `[redacted]`)。

## 后果

- 部署环境必须提供 `git` 可执行文件(Docker 镜像包含即可);
- 未来若需纯 JS 或无 git 环境,可替换 GitClient 实现,接口不变。
