# ADR-0004:应用模板采用静态模板目录

- 状态:Accepted(用户于 2026-08-04 确认)
- 日期:2026-08-04
- 关联:PRD 阶段 6 / AGENTS §18

## 背景

阶段 6 交付 workbench app template。候选:静态模板目录(templates/workbench-app)、
CLI 脚手架(pnpm create)、仅以 reference-app 为样板。

## 决策

采用**静态模板目录** `templates/workbench-app`:

- 最小独立应用仓库结构(apps/server、apps/web、apps/mcp、apps/desktop 占位、
  modules/、config/application.ts、deploy/、docs/);
- 使用步骤写入模板 README;reference-app 作为可运行参照;
- 部署模板(Docker Compose + Caddy + Litestream)与备份恢复文档随模板交付。

## 后果

- 新应用通过复制模板起步;CLI 脚手架留作未来增强,不影响模板内容。
